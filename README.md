# AI 广告视觉提示词库（ad-visual-prompter）· 入门使用说明

一个内置 **127 条经实测的竖版（3:4）广告生图提示词** 的技能：输入编号或描述需求，即可获得完整提示词原文；说"直接出图"还能自动生成对应广告图片。

## 一、安装（一次性，约 1 分钟）

1. 解压本压缩包，得到 `ad-visual-prompter/` 文件夹
2. 把整个文件夹放入技能的根目录（豆包 / Agent 环境通常是 `~/.agents/skills/`，与其它技能并列）
3. 在对话中开始使用（无需重启）

> 必须把 `assets/` 图片目录一起放入，画廊里的效果图才能正常显示。

## 二、怎么用（对话直接说，无需记命令）

| 你想做什么 | 这样说 |
|---|---|
| 查某个编号的提示词 | 「查一下 PA-012 的提示词」 |
| 指定分类找提示词 | 「给我几条产品展示类的提示词」 |
| 按需求推荐 | 「我要一张高端威士忌广告海报的提示词」 |
| 直接出图 | 「直接出图 CA-043」 |
| 不确定编号 | 「提示词库里有奶茶类的吗」 |

AI 会自动识别并返回 **完整提示词原文**（可逐字复制使用）；只有明确说"出图/生成图片"，才会调用生图工具。

## 三、编号规则（认识编号）

编号 = 分类前缀 + 三位序号，例如 `PA-012`：

| 前缀 | 分类 | 数量 |
|---|---|---|
| PA | 产品展示 | 81 |
| CA | 内容创作 | 32 |
| BV | 品牌视觉 | 6 |
| MK | 营销推广 | 5 |
| EC | 电商运营 | 3 |

说"产品展示 12 号"、"第 3 条内容创作"也能识别。

## 四、浏览画廊（可选）

打开技能包内的 `gallery/index.html`（双击即可，无需联网）：

- 按分类/搜索浏览 127 张效果图（3:4 竖版）
- 点击卡片弹出详情：大图 + 完整提示词 + 一键复制
- 搜索框直接输编号（如 `CA-043`、`043`）自动匹配
- 支持小/中/大三档尺寸切换

## 五、常见问题

**Q：画廊图片空白？**
→ 技能包没带全：确认 `assets/gallery/` 目录存在，与 `gallery/index.html` 同级。

**Q：说编号没反应 / 提示词不对？**
→ 编号必须是库内真实编号；不确定时用"推荐"说法，或直接描述需求。

**Q：想要新的提示词（新增条目）？**
→ 本包是数据快照，新条目需由技能作者从源表导出更新后再发新版。

**Q：生图效果与效果图有差异？**
→ 提示词是唯一依据；效果图仅作风格/版式参考，不同模型渲染会有差异，属正常。
